📸 Picture to Anime Converter (OpenCV)

A lightweight and beginner-friendly project that converts normal images into anime-style photos using OpenCV. This tool applies edge detection, smoothing, and custom filters to give your picture an anime-like effect. Perfect for learning image processing and experimenting with creative OpenCV techniques.

⭐ Features

Anime-style image conversion

Smooth cartoon-like effects

Fast processing using OpenCV

Works with JPG, PNG, and other formats

Simple and easy to modify

🛠️ Technologies Used

Python

OpenCV

Numpy

🚀 How to Use

Clone the repository

Install required libraries:

pip install opencv-python numpy

python anime_converter.py
